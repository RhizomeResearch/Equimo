# SAM 3.1 behavior provenance

Equimo's SAM 3.1 port was first drafted from `docs/designs/sam3.md`, Equimo, the SAM 3 paper and the SAM 3.1 release
post, without reading the reference source. The tiny component tests then compare it against the reference at
`f1647e8d0c1d280991f4d1b7d974c2704537fe66`. Each row records a behavior that differed, the test that caught it, and the
revision that fixed it. The code stays under `MIT AND Apache-2.0`; this note is the record of what changed after reading
the reference, and it is not legal advice.

| Behavior corrected                                                                                                                                                                   | Test                                                                                             | Revision   |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------ | ---------- |
| The joint logit goes through `inverse_sigmoid` with a 1e-3 clamp, so it stays within about +/-6.9.                                                                                   | `tests/test_sam3.py::test_joint_score_and_boxes_match_the_reference`                             | `tksqkunw` |
| Geometry prompts sum separate direct, pooled and position projections, add a class token, normalize the image first, and use a final projection and norm.                            | `tests/test_sam3.py::test_geometry_encoder_matches_the_reference_with_exemplars`                 | `tksqkunw` |
| The box relative-position bias uses signed log-scaled offsets to both box edges, with one network per axis.                                                                          | `tests/test_sam3.py::test_decoder_matches_the_reference`                                         | `tksqkunw` |
| The decoder's text cross-attention takes box positions; box positions are sine-encoded in y, x, width, height order; the queries and the presence token have their own output norms. | `tests/test_sam3.py::test_decoder_matches_the_reference`                                         | `tksqkunw` |
| Scoring refines the prompt with a residual network and norm, then scales the dot product by `1 / sqrt(dim)`.                                                                         | `tests/test_sam3.py::test_scoring_matches_the_reference`                                         | `tksqkunw` |
| The segmentation head runs 2 pixel-decoder stages and has separate instance and semantic projections.                                                                                | `tests/test_sam3.py::test_segmentation_matches_the_reference`                                    | `tksqkunw` |
| The two-way transformer adds position encodings per attention, its first block adds no self-attention residual, and it ends with a final cross-attention.                            | `tests/test_sam3.py::test_interactive_decoder_matches_the_reference`                             | `tksqkunw` |
| Each mask token has its own mask-embedding network, and the upsampler has a single norm.                                                                                             | `tests/test_sam3.py::test_interactive_decoder_matches_the_reference`                             | `tksqkunw` |
| The prompt encoder always appends a padding point, and an empty prompt also encodes one padding point in the first slot.                                                             | `tests/test_sam3.py::test_prompt_encoder_matches_the_reference_for_masks_and_boxes`              | `tksqkunw` |
| A mask prompt follows the stability rule even with no points.                                                                                                                        | `tests/test_sam3.py::test_interactive_decoder_matches_the_reference`                             | `tksqkunw` |
| Multiplex slots have their own object, IoU and mask tokens; valid and invalid embeddings apply only to mask tokens; the decoder takes no sparse or dense prompts.                    | `tests/test_sam3.py::test_multiplex_decoder_matches_the_reference`                               | `tksqkunw` |
| The memory encoder's channel widths grow by 4 from `start_channels`, and its fuser depth is configurable.                                                                            | `tests/test_sam3.py::test_memory_encoder_matches_the_reference`                                  | `tksqkunw` |
| Memory attention adds projected image features to its queries and keys, adds position to the keys, scales the input position by 0.1, and uses exact GELU in its feed-forward.        | `tests/test_sam3.py::test_memory_attention_matches_the_reference`                                | `tksqkunw` |
| The causal text encoder does not drop padded keys; right padding cannot reach real tokens through the causal mask.                                                                   | `tests/test_language.py::test_causal_text_transformer_matches_the_reference_on_the_tiny_fixture` | `tksqkunw` |
| `roi_align` reads the border for samples outside the map, as torchvision's CUDA kernel does, instead of zeroing samples further than a pixel away.                                   | `tests/test_vision_ops.py::test_roi_align_matches_torchvision`                                   | `tksqkunw` |
| Bilinear mask resizing uses torch's float32 sample positions, through `resize_bilinear`.                                                                                             | `tests/test_vision_ops.py::test_bilinear_resize_matches_torch`                                   | `tksqkunw` |
| Single-frame mask NMS measures overlap as intersection over minimum, not against the higher-ranked mask's area.                                                                      | `tests/test_sam3.py::test_mask_nms_keeps_what_the_reference_keeps`                               | `tksqkunw` |

The reference's own numerics also needed one correction, in the fixture harness rather than the port. Importing
`sam3.model.sam3_multiplex_base` turns TF32 on for convolutions and matmul, so the harness now restores float32 after
that import. `models/sam31_reference.py:float32_reference` carries the fix.
